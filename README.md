# sunweihunu.github.io

课程网站总入口（GitHub Pages 用户主页）。修改 `index.html` 后推送至 `main` 分支即可即时更新。

| 课程 | 地址 |
|------|------|
| 人工智能与地理数据挖掘 | <https://sunweihunu.github.io/ai-geo-data-mining/> |

## 新增课程入口的方法

1. 为新课程单独建仓库并启用 GitHub Pages（参照 [ai-geo-data-mining](https://github.com/sunweihunu/ai-geo-data-mining) 的 MkDocs + Actions 模式）；
2. 在 `index.html` 的 `.grid` 中复制一个课程卡片，填入标题、简介与网址，提交推送即可。
